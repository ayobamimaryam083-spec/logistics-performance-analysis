## Project Overview
This project involves the analysis of logistics operations using Microsoft Power BI. The dashboard provides insights into fleet performance, driver efficiency, route and customer profitability, fuel consumption, and vehicle maintenance.

## Objectives
- Analyse fleet utilisation and performance.
- Evaluate driver performance and safety incidents.
- Identify profitable routes and customers.
- Examine fuel expenses and vehicle maintenance costs.
- Generate insights to support operational decision-making.

## Tools Used
- Microsoft Power BI
- Microsoft Excel
- GitHub

## Key Findings
- Total revenue was approximately 263 million.
- Total trips reached 85,000.
- Dedicated bookings accounted for approximately half of all loads.
- Driver completion rates were high among the leading drivers.
- On-time delivery performance requires improvement.
- Fuel and maintenance expenses represent important areas for operational monitoring.
